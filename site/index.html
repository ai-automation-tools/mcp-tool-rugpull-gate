See what changed in your MCP tools since you approved them

An MCP server can quietly change a tool's description, schema or hints after you approved it. mcp-tool-rugpull-gate locks the tools/list you approved into a file and, on every check, tells you in plain words what changed and which changes look risky. It reads files only: no server is started and nothing goes over the network.

This page will let you paste an approved and a current tools/list and see the diff, using the same engine as the CLI.
